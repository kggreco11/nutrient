# Inter 4.1

Unmodified static OpenType fonts from the official [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), `extras/otf/`. Regular, Medium, SemiBold and Bold are bundled through UIAppFonts and Xcode’s Fonts resource folder. Copyright and SIL Open Font License 1.1 are included in [LICENSE.txt](LICENSE.txt).

The app’s semantic type helper maps to the named faces and uses SwiftUI’s `relativeTo` scaling for Dynamic Type. No network font loading is used.
